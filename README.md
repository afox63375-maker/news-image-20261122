# Sunday 22 November 2026 — The World in One Day

A one-page newspaper front page that sums up Sunday 22 November 2026 in
39 stories. `main.py` draws the whole page programmatically with Pillow
(real DejaVu fonts, no network, deterministic output) and writes
`/output/entry.png` (1024×1024 PNG).

The page names the day it sums up, leads with three illustrated stories,
then a story grid, a dotted world map with numbered, category-coloured pins
that match the story list, a regional stat strip, a numbered brief list, a
weather forecast panel for four cities instead of any AI logo, and a
date-check footer that separates Friday's and Saturday's events from
Sunday's developments.
